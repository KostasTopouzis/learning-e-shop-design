# Starting point: simple full-stack, no commerce depth yet

The user can build and deploy simple full-stack apps (UI + backend API + database) and has a React storefront for The Edit deployed on Vercel. They have not yet designed a commerce data model, cart or checkout, and they plan to migrate to Next.js + Postgres. Start at catalog data modelling and assume basic SQL and React; don't assume they know commerce-specific patterns (variants, money storage, idempotency, inventory reservation, order snapshots).

**Evidence**: self-reported at the first session (2026-10-25).
